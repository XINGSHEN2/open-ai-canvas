# 内网免登录创作

此功能只用于受信任内网，不是公网匿名生成服务。管理员后台保留正式登录，已有管理员账号和密码不变。

## 身份与权限

- 浏览器初始化会话时，后端仅在访客开关开启、来源 IP 命中显式 CIDR 白名单时返回 `localGuestEnabled=true`。
- 前端随后 POST `/api/auth/guest`，创建随机的普通用户身份及 HttpOnly/SameSite Cookie；不是共享管理员或全局访客账号。
- 每个浏览器独立拥有任务、资源、画布和历史。Cookie 保留时可继续访问；清除 Cookie、换浏览器或会话过期后，不会自动找回之前访客身份。需长期可靠保存的工作仍建议正式登录或主动下载。
- 访客没有可用于密码登录的密码，不发放注册奖励。管理员接口、账号凭据操作、自定义上游、原始渠道代理、插件管理及 Agent 接口对访客拒绝。
- 访客任务的渠道和上游模型必须重新从服务器数据库解析，并限定到本地 Qwen 2.1 / H3 Ref2VA；不信任客户端传来的 Base URL。
- 继续复用正常任务的限流、并发配额、持久化队列与资源归属校验。
- 自动访客创建按来源 IP 限制每小时10次；目前不自动清理过期访客用户/历史，需要按保留策略运维管理，不能无限暴露给不受信网络。

## 配置

默认关闭。部署时显式设置：

```bash
CANVAS_LOCAL_GUEST_ENABLED=true
CANVAS_LOCAL_GUEST_CIDRS=10.42.0.0/16,172.16.8.1/32,127.0.0.1/32,::1/128
CANVAS_PUBLIC_BASE_URL=http://10.42.1.2:3000
CANVAS_ALLOWED_PRIVATE_UPSTREAM_HOSTS=10.42.1.1,10.42.1.2
```

`172.16.8.1/32` 是当前浏览器访问链路观测到的内网网关，迁移时应重新确认，不应照抄或扩大成所有私网。来源白名单和模型上游白名单是两件不同的事。

后端仅信任 loopback 反向代理的转发 IP；直接请求伪造 X-Forwarded-For 不能获得访客权限。若换反向代理部署，必须同步审查可信代理列表。CIDR 缺失或非法时失败关闭。

访客仅在初始化管理员后开启。`/api/auth/guest` 不接受跨来源 Origin。正式账号仍可通过首页“管理员登录”进入 `/login`，不会被自动访客重定向拦截。

## 本地模型初始化

先对 SQLite 数据库做一致性备份，再由拥有数据库部署权限的运维人员执行：

```bash
cd backend
CANVAS_BACKEND_DATA_DIR=/absolute/data/path \
CANVAS_ALLOWED_PRIVATE_UPSTREAM_HOSTS=10.42.1.1,10.42.1.2 \
go run ./cmd/provision-local-services --apply --free-internal \
  ../deploy/local-services/local-models.json
```

这是离线部署命令，不是新开放的匿名配置 HTTP API。它要求现有数据库只有一个活动管理员，调用已有管理员服务校验，按名称和模型 key 更新同一记录；不改管理员权限或密码。`--free-internal` 是明确将这两个本地模型设置为0积分，不影响其它模型价格。

模型服务位置：Qwen `10.42.1.1:9008/v1`；H3 `10.42.1.2:30011`。不重启模型 Worker。

Qwen 使用网站已有标准 Images 请求路径，不使用通用插件的 JSON参考图/额外resolution字段；文生图为JSON，编辑为multipart。其它模型的协议插件保持原样。

H3 模型仅参考生成：必须至少一份图片/视频/音频，480P/768P，5–15秒；UI无参考时禁止发送，服务端再次校验。没有“关闭音频”功能，前端不开放该开关；能力合同的关闭状态只表示不提供这个可选控制，并非承诺生成静音视频。

## 验证结果

- auth、handler、app 的专项测试通过；覆盖独立访客会话、普通用户角色、默认关闭、CIDR失败关闭、转发IP伪造、Qwen标准JSON/multipart、H3必需参考及尺寸/时长限制。
- 官方前端 build（含 TypeScript 检查）通过。
- 浏览器实际免登录进入工作区，Qwen/H3可选，文本与Agent禁用。
- 访客图片生成真实成功：1024×1024，约22.5秒。
- 访客视频生成真实成功：H3参考图片，480P、16:9、5秒，约90秒，结果保存到网站资源库。
- 另一个访客读取上述任务返回404；访客访问管理员接口返回403。

测试是最小链路验收，不代表所有分辨率、所有参考素材组合或长时间压力测试已覆盖。HTTP模式仅供可信内网，正式使用真实凭据或开放更广网络前应启用HTTPS。
